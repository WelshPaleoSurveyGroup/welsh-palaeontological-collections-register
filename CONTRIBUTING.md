# Contributing

Contributions are welcome, particularly:

- new Welsh specimen records;
- corrections to catalogue numbers, taxonomy, type status, locality, or stratigraphy;
- links to museum records, primary literature, photographs, IIIF manifests, CT datasets, or 3D models;
- information on historical collections and specimen transfers;
- clarification of unresolved questions already listed in the register.

## Before proposing a new specimen

Please provide as many of the following as possible:

1. repository/institution;
2. catalogue or accession number;
3. taxon as stated by the source;
4. anatomical element or specimen description;
5. Welsh locality as stated by the source;
6. geological/stratigraphic information;
7. collector and collection date, if known;
8. type or figured status;
9. primary source URL or full bibliographic reference;
10. any photograph, scan, CT, or 3D resource link.

## Evidence standard

A record should be independently relocatable. Repository + catalogue number is preferred.

Vague statements such as “several specimens are held at Museum X” are useful research leads but should be logged as unresolved/candidate information rather than as permanent specimen records.

## Preserve source wording

Historical labels, obsolete taxonomic names, and old locality names should be preserved verbatim before normalisation. Do not silently replace historic wording with modern interpretations.

## Sensitive localities

Do not submit precise coordinates for vulnerable, private, restricted, or actively collected fossil localities in a public issue. State that the precise locality is available privately to project maintainers if necessary.

## Workflow

- Use an issue for a single correction, uncertain record, or proposed specimen.
- Use a pull request for a batch of records or documentation changes.
- Candidate records should be verified before receiving permanent `WPR-*` IDs.
